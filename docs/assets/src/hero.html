Test coverage
you cannot fake.

A Claude Code workflow that raises coverage and pass rate one module at a time, and mutates your source to delete every test that cannot fail.
01
Measured, never pasted
A fresh local coverage run is the baseline. No suite, no number.
02
A mutation gate per module
Break the covered line. A test that still passes is deleted.
03
Branches, never merges
Each module's tests land on a local branch for a human to review.
10% PER ROUND · STOP AFTER 2 FLAT ROUNDS · 0 MERGES
